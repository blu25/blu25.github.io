{%- comment -%} Background photo for a tile. Sizes come from _data/images.yml (npm run images). name: photo name, e.g. ic-lights size: the tile's size classes, e.g. "w2 h2" alt: description ("" for decorative) lazy: true to load it once scrolled near {%- endcomment -%} {%- assign img = site.data.images[include.name] -%} {%- assign size = include.size | append: "" -%} {%- assign cols = 1 -%}{%- if size contains "w3" -%}{%- assign cols = 3 -%}{%- elsif size contains "w2" -%}{%- assign cols = 2 -%}{%- endif -%} {%- assign rows = 1 -%}{%- if size contains "h2" -%}{%- assign rows = 2 -%}{%- endif -%} {%- comment -%} The photo covers its tile, so a tile that is taller than the photo's shape shows it wider than the tile. Tiles are a third of the page wide and 25vw tall; on phones 100vw by 40vw. {%- endcomment -%} {%- assign aspect = img.width | times: 1.0 | divided_by: img.height -%} {%- assign tile_w = cols | times: 33.3 -%} {%- assign shown_w = rows | times: 25 | times: aspect -%} {%- if shown_w < tile_w -%}{%- assign shown_w = tile_w -%}{%- endif -%} {%- assign phone_w = aspect | times: 40 -%} {%- if phone_w < 100 -%}{%- assign phone_w = 100 -%}{%- endif -%} {%- assign largest = img.base | append: '-' | append: img.width | append: '.avif' -%}
